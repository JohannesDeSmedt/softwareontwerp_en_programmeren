Waar vind ik mijn token?
Optie 1: Kijk in het terminalvenster waar je de server gestart hebt. Daar staat een regel zoals http://localhost:8888/?token=3f9a1b2c... — alles na token= is je token.
Optie 2: Staat de server al open in je browser? Kijk dan in de adresbalk van dat tabblad — ook daar staat ?token=....
Optie 3: Typ in een nieuw terminalvenster jupyter notebook list (of jupyter server list) terwijl de server draait — dat toont de URL met token van elke actieve server.
Nog geen server gestart? Kopieer dit commando in een Terminal-venster (macOS) of een (Anaconda) Prompt-venster (Windows) en druk op Enter:
Hoe open ik een Terminal of Anaconda Prompt?
macOS: druk op ⌘ + Spatie, typ "Terminal" en druk op Enter.
Windows: klik op Start, typ "Anaconda Prompt" (als Anaconda geïnstalleerd is) of "cmd", en klik op het resultaat.
Zodra het pad hierboven is ingevuld, openen alle "Open"-links op deze pagina het notebook rechtstreeks in VS Code — geen server nodig.
🐍 VS Code gebruiken met de Anaconda "base"-kernel
1. Zorg dat de extensies Python en Jupyter (beide van Microsoft) geïnstalleerd zijn in VS Code (tabblad Extensions, links in de zijbalk — of ⌘/Ctrl+Shift+X).
2. Open een notebook via een link op deze pagina, of via de knop hierboven.
3. Klik rechtsboven in het notebookvenster op "Select Kernel".
4. Kies "Python Environments…" en selecteer de omgeving genaamd "base" — dat is je standaard Anaconda-installatie.
5. VS Code onthoudt deze keuze per notebook: dit moet je normaal maar één keer per notebook doen.
Wil je dat elk notebook in deze map automatisch met "base" start, zonder telkens te moeten kiezen? Maak in deze map een bestand .vscode/settings.json met daarin het pad naar jouw Anaconda-python, bijvoorbeeld:
{ "python.defaultInterpreterPath": "<pad naar anaconda3/bin/python of anaconda3\python.exe>" }
Dit pad verschilt per computer (macOS meestal ~/anaconda3/bin/python of ~/opt/anaconda3/bin/python; Windows meestal C:\Users\...\anaconda3\python.exe) — makkelijker is stap 3-4 hierboven te volgen, dat werkt altijd zonder paden op te zoeken.
⚠️ Geen "base"-omgeving te vinden? Zo los je dat op
Deze pagina kan niet automatisch controleren of Anaconda op jouw computer geïnstalleerd is — een webpagina heeft daar geen toegang toe. Volg deze stappen om het zelf na te gaan:
Controleren of Anaconda geïnstalleerd is:
• Zoek naar en open "Anaconda Navigator" via Spotlight (macOS) of het Start-menu (Windows). Verschijnt het niet? Dan is Anaconda waarschijnlijk niet (correct) geïnstalleerd.
• Of typ conda --version in een Terminal/Anaconda Prompt. Krijg je een versienummer terug, dan werkt Anaconda.
Als Anaconda wél werkt, maar niet verschijnt in VS Code's "Select Kernel":
• Herstart VS Code volledig nadat je Anaconda geïnstalleerd hebt — de Python-extensie zoekt omgevingen enkel bij het opstarten.
• Controleer of de Python-extensie geïnstalleerd en ingeschakeld is (zie stap 1 hierboven).
• Klik bij "Select Kernel" op het vernieuw-icoontje, of gebruik Command Palette (⌘/Ctrl+Shift+P) → "Python: Select Interpreter" om te zien welke omgevingen VS Code vindt.
Als het commando hierboven ("jupyter notebook") een foutmelding geeft zoals command not found: jupyter (macOS) of 'jupyter' is not recognized (Windows): Anaconda staat niet op het PATH van je systeem. Gebruik dan specifiek de "Anaconda Prompt" (Windows) in plaats van een gewone terminal, of herinstalleer Anaconda met de optie "Add Anaconda to my PATH environment variable" aangevinkt.
Nog steeds vastzitten? Herinstalleer Anaconda via anaconda.com/download en probeer opnieuw.
